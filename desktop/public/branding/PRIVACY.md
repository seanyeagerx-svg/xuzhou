# 续舟隐私说明

适用于 2.2.3 Windows 发行候选，更新于 2026-10-16。

续舟基于 AionUi / AionCore，连接用户自行安装或授权的 AI 客户端与服务。发行包不附带开发者的聊天、账号、服务器配置、SSH 密码、浏览器登录状态或诊断档案。

## 本机保存什么

项目、聊天正文、会话接续记录、同步状态和日志保存在用户的应用数据目录或自行选择的项目目录。聊天数据库是普通 SQLite，部分配置是 JSON；它们没有应用级全文加密。本机文件权限、Windows 账户安全与磁盘加密仍决定谁能读取它们。凭据存储使用 Windows 当前账户的系统加密接口，不能据此推断聊天正文也已加密。SSH 本次密码仅用于当前维修连接，不写入发行配置。

## 什么时候会发送数据

发送消息、切换 AI 接续时，会将本轮问题、必要历史摘要和用户选择的文件交给对应服务或本机客户端。超长对话可通过本机历史检索工具取回原文，相关原文也可能进入后续模型请求。外部提供商使用数据的规则由其条款决定。

Codex、Kiro V3 等自动同步会读取并更新用户本机的会话记录；它不是每次扫描都向模型发起请求。龙虾的询问、同步或自动旁听会把当前功能选择的内容发送到用户配置的 OpenClaw Gateway。自动旁听模式由每个聊天的设置控制，可关闭。Grok 原客户端嵌入仍使用其自身账号和服务。

本版本关闭 Sentry 初始化、诊断上传、启动日志上报与遥测设备标识创建，即使构建环境设置上游 SENTRY_DSN 也不能恢复上传。反馈上传按钮禁用。用户主动选择“在对话中解决”会把自己选择的说明、附件交给该对话使用的 AI，应先检查内容。关闭诊断不意味着模型、Gateway 或用户打开的网站不会联网。

## 电脑与手机连接

手机通过现有 Tailscale 私网配对。两分钟单次二维码仅供自己控制的设备使用，配对会话最长十二小时，关闭程序、到期或撤销会使其失效。手机入口复用完整 WebUI，拥有主人的全部项目、聊天与工作台操作权限，**不限制为扫码时的一个聊天**；生成二维码前必须在电脑主动确认这一权限。不要分享给他人。

屏幕接管必须在电脑单独开启，支持暂停、撤销及 Ctrl+Alt+Shift+X 紧急停止。命令以当前本机账户或用户配置的 SSH 账户执行；工作目录与文件操作的路径检查不是操作系统沙箱。AI 发起的受控写入或命令走已有审批流程；用户直接点击执行的命令按用户指令执行。屏幕图像、文件与命令结果可能含有隐私，应只向自己授权的对象提供。

## 保留、导出与删除

本版本不自动清理旧聊天或用户文件。卸载不会主动清空个人聊天目录。可使用产品现有的聊天删除与导出功能，或在退出软件并备份后自行管理应用数据；原生客户端、备份、远端 Gateway 和外部服务可能仍保留副本，需要分别管理。发布源码仅取明确列入清单的文件，排除本机数据、证据、日志、数据库和密钥。

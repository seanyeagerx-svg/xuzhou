# 续舟安全说明

安全报告请使用项目 GitHub 的私密漏洞报告入口（若已启用），或维护者在仓库明确公布的私密联系方式。当前候选尚未建立公开仓库与私密联系入口，不要向公共 Issue 粘贴密钥、聊天、屏幕截图、服务器地址或完整日志。对外发布前必须确认私密报告渠道可用。

当前核验范围为 Windows x64 2.2.3 候选。使用受支持的 Electron 44.8.0，依赖原始许可随包保留。浏览器权限默认拒绝，只有受信任主界面的本机字体枚举自动允许；摄像头、麦克风、位置、硬件设备与未知权限没有默许授权。屏幕接管通过产品已有独立开启与撤销机制，不依赖网页自动许可。

手机配对是完整主人权限，不适合作为分享某一聊天的机制。二维码与配对 cookie 都属于访问凭证。监听仅使用现有 Tailscale 私网地址，普通公网监听被拒绝；状态更改和 WebSocket 要求精确 Origin。撤销会关闭对应连接并取消该手机发起的运行中设备操作。

安全扫描是对指定源码与打包文件的本地检查，不构成“绝无漏洞”的保证。未知、未复核的密钥命中、缺少的许可、未通过的安装包验证都会阻止发布。任何依赖升级或后续改包都必须重新检查。普通 SQLite 与项目文件没有应用级全文加密。

发行不包含模型厂商登录凭据或服务额度。不要通过复制他人令牌、转卖账户或绕过外部客户端限制接入服务。

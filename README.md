# 续舟 Xuzhou · 2.3.1-beta.2

在同一段聊天里选择 Codex、Kiro V3 或 ZCode，带着可见前文继续工作。续舟维护软件与模型选择、接续位置、历史检索和同步回执；底层复用 AionUi / AionCore，保留 Apache-2.0、原作者及第三方声明。

本目录是 Windows x64 公开测试版的发行材料。上传状态与验收范围以随附发行报告为准。安装包没有 Windows 代码签名，当前采用手动更新。

## 安装与聊天保护

1. 核对 SHA256SUMS.txt，运行 Xuzhou-2.3.1-beta.2-win-x64-setup.exe。
2. 从“续舟测试版”快捷方式启动。Beta 默认安装到 Programs/XuzhouBeta，聊天保存在独立的 AppData/Roaming/XuzhouBeta 目录。
3. Codex、Kiro V3、ZCode 需要自行安装并登录，续舟不附带账号、订阅或服务额度。
4. 左侧“控制中心”可查看实验功能提示、连接、备份和更新设置。

Beta 不自动接管原版聊天目录、旧工作台配置、快捷方式或 aionui 链接。原版可继续使用。Codex 本地项目列表读取本机原生记录；打开聊天与同步属于后续用户操作。参见 [聊天保护说明](docs/UPGRADE.md)。

## 验证与限制

文字接续与指定同步场景已有真实客户端验证。ZCode 原生双向同步、Grok 共享上下文、音频、真实云机、实体手机、真实外置盘恢复、夸克备份及自动更新仍有未接通或未验收部分。

本版修复新聊天无模型可选、Kiro 模型列表丢失、重启后切换 ZCode 失败，并将团队成员接入本机 Codex、Kiro V3 和 ZCode。Claude 软件及上游预置助手不再作为新建入口；已保存的历史聊天和开源声明继续保留。Kiro 自身提供的 Claude 系列模型仍属于 Kiro 模型目录。

团队成员按具体 AI 型号选择，同一个接入来源可以选择多个不同型号。创建后可继续添加或移除成员，移除会保留该成员的本地聊天与项目文件。团队共享项目目录、任务和协作消息；各成员的完整私人聊天不会自动广播。目前保留一名协调 AI，协调 AI 的模型可通过已有模型控件调整。

点击会动的小龙虾，可打开协作动态、对话与同步、旁听整理、维修和连接。它在续舟窗口内可拖动，进入团队或聊天时会按项目目录匹配龙虾项目。协作动态显示已收到的收发内容、汇报和工具事件；“待同步”或“排队中”不代表已经送达或执行完成。云端真实工具记录仍需连接后的实机核验。

MCP 工具确认可选择“允许此工具，本聊天不再询问”，重启后继续生效，也可以在聊天或团队的模型菜单中撤销。授权按聊天、AI、工具和连接配置区分；原生命令、文件操作及需要填写答案的表单仍由各自授权流程处理。

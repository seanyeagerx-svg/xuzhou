# 清洁环境验证与边界

本轮在现有 Windows 11 x64 主机上使用全新的应用数据、提供商配置、临时目录和聊天目录验证最终安装程序。启动环境移除开发覆盖变量与模型服务凭据，初始 PATH 只提供 Windows 系统目录；客户端自己的路径恢复机制仍按产品正常行为运行。

验收应核对：从最终安装包安装、正常启动主窗口、独立 Beta 数据目录、内置 Core 与 Node、控制中心和功能限制提示、没有预置聊天/服务器配置、隔离命令与中文文件往返、模型未安装时如实提示、手机配对默认未授权、备份与更新默认关闭。子进程路径与安装文件逐项校验用于确认运行没有依赖开发源码或开发 node_modules。

这是同一主机的清洁应用环境测试，不能称为第二台电脑、全新 Windows 账户或全新 Windows 系统测试。本机 Windows 家庭版没有可用 Windows Sandbox，本轮不更改系统版本、虚拟化组件、代理或重启设置。发行报告必须保留这一边界。

在另一台 Windows 10/11 x64 机器上，仍应再次验证安装、客户端登录、聊天切换、更新、退出与卸载。实体手机、真实外置盘和远端云机另行验收，不包含在桌面启动检查中。

Windows 注册的 USERPROFILE/HOME 必须保留，否则系统已知文件夹接口会失败；默认 Beta 数据目录另行验证。

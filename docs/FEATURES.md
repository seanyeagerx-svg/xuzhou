# 2.3.1-beta.2 功能与验收范围

“真实验证”只覆盖对应客户端、版本与新建验收聊天；合成数据测试不代表个人资料、实体设备或长期运行已验收。最终打包复验与可复用组件证据分别列在 verification 中。

| 功能 | 当前范围 | 尚未接通或验收 |
|---|---|---|
| 同一聊天切软件和模型 | Codex、Kiro V3、ZCode 文字接续已有真实回复证据 | 未覆盖所有账户、模型和工具授权流程 |
| 新聊天与团队 | 发送前可选择真实软件模型；团队按具体 AI 型号创建与追加，同一接入可选多个型号；移除成员会保留本地聊天和项目文件 | 未覆盖全部团队模型；保留一名协调 AI，完整私人聊天不会自动广播 |
| Codex 原生同步 | 写入、原生回复导入、防重复、重启回执已有真实验证 | 旧历史全部附件与所有并发场景未覆盖 |
| Kiro V3 同步 | 新对话双向同步已有真实验证 | 旧 Kiro 会话接管未验收 |
| ZCode 原生双向同步 | 统一聊天文字接续保留 | 未找到合适的无回复原生历史注入方式，不宣称完全双向同步 |
| Grok Bot | 原客户端入口 | 无统一上下文与双向同步 |
| 图片 | 新图保存，Codex → Kiro V3 图片接续已有真实验证 | 不保证全部旧历史图片或其他客户端支持 |
| 音频、工具状态 | 未统一 | 尚未接通 |
| 超长聊天 | 完整原文检索、1,000 次模拟切换测试 | 未完成多日真实运行与全部断网冲突验收 |
| 龙虾面板与小龙虾 | 可拖动的动画入口，点击展开对话、同步、旁听、维修和连接；团队自动关联同目录项目 | Gateway 送达、维修 SSH、任务完成必须分别核验；悬浮入口位于续舟应用内 |
| 龙虾协作动态 | 展示本项目的收发内容、汇报正文、回执与已收到的工具事件；聊天旁提示最新状态 | 不补造未收到的云端过程；本轮云机执行仍需单独实机验收 |
| 工具访问记忆 | 可在具体 MCP 工具确认时记住本聊天授权，按聊天、AI、工具及连接配置区分；聊天与团队均可撤销 | 原生文件、命令、问答表单和独立维修授权不被整体关闭 |
| 云机执行 | 保留连接、命令、文件入口 | 本次可信 SSH 主机密钥、容量及真实命令文件闭环未完成；不默认启用 |
| 本机命令、文件 | 隔离项目中的命令与中文文件往返可验收 | 不是操作系统沙箱，按当前 Windows 账户权限执行 |
| 屏幕接管 | 实验功能，原生拖拽和暂停已有验证 | 缺音频、高帧率及更多实际应用覆盖 |
| 手机 | 布局、配对权限与撤销机制测试 | 无实体手机完整验收；配对拥有完整主人权限 |
| USB 定时备份 | 实验功能，默认关闭；合成数据验证加密、调度、一致快照和样本恢复 | 无真实外置盘与完整恢复验收；单文件上限 256 MiB |
| 夸克备份 | 未接通 | 无上传、重试和云端恢复闭环 |
| 自有更新 | HTTPS/Ed25519 清单校验测试 | 无公开更新服务或自动下载安装；目前手动更新 |
| Windows 代码签名 | 未签名测试版 | 无代码签名证书，校验值不替代可信发布者签名 |
| 界面自主化 | 自有导航、接续与同步界面、控制中心 | 部分设置与底层组件仍复用 AionUi / AionCore |

本版不包含第三方账户、订阅、服务额度或厂商登录凭据，也不绕过外部软件的权限和限制。
